# Steam Tweak Tool

## Introduction
Steam Tweak Tool is a command-line tool for managing game updates and cloud data for the Steam Client.

## Features
- Disable or Enable Game updates (Great for modders)

- Disable all Auto-updates

- Unschedule all game/workshop updates

- Disable Steam Cloud for all games (per-game settings)

- Delete Steam Cloud data

## How to build
Install Zig, and run ```zig build``` in your terminal at the project root.
